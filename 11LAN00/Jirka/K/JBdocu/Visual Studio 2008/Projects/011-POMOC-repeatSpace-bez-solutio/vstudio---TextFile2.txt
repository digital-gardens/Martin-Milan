' Hi there,
' You may try the following,
'
' Select the Microsoft Visual Basic 6.0 shortcut from the Start menu and right-click on it.
' Select Properties, and the property sheet for the shortcut will be displayed.
' Next, click on the Compatibility tab. It is recommended that you make the following changes:
'   1. Enable compatibility mode and select Windows XP (Service Pack 3) .....
'   2. Check the "Disable visual themes" option .....           ("Zakázat motivy")
'   3. Check the "Disable desktop composition" option.....      ("Zakázat kompozici plochy")
'   4. Check the "Run this program as an administrator" option  ("Spustit tento program jako správce")
'
' Click on OK to save the changes. When you run Visual Basic, a User Account Control (UAC)
' dialog will be displayed, asking you to confirm that you wish to execute the program.
' This is because it's now running with elevated privileges.
' You may also get a message that the color scheme has been changed to Windows Vista Basic.
' The Aero interface will be temporarily disabled until you close the IDE,
' which will resolve the performance issues with the form designer.

' Casto se vyskytuje pri prenosu programu na jiny (nebo preinstalovany) stroj!
' Nekdy zmizi ProgressBar (Main) a Slidery (Graf, RegProgramNew) proto,
' ze v Project -> Components se "ztrati" zaskrtnuti (vyber) nekolika knihoven.
' Naprava:
'   1) v Project -> Components vybrat knihovny:
'         LEDdt
'         Microsoft Comm Control 6.0
'         Microsoft Common Dialog Control 6.0 (SP6)
'         Microsoft Hierarchival FlexGridControl 6.0 (SP4)
'         Microsoft Windows Common Controls 6.0 (SP6)
'   2) zakreslit ProgressBar do frmMain a slidery do frmGraf a frmRegProgramNew
'        podle obrazku
'
'   3) prejmenovat objekty:
'         ProgressBar1 v frmMain
'         sldPosuvOsyX v frmGraf
'         sldPocatecniIndex v frmRegProgramNew
