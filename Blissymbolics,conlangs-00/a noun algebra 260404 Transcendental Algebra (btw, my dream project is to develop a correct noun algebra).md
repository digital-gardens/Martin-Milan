One particularly useful emoji is 🧩. It can mean something like component / constituent, while 🔗 works naturally for relation, 🏷️ for type/category/label, and 🔣 for symbol/sign. These are more meta-ontological than ordinary pictograms.

A useful next experiment would be to define perhaps 10–20 top-level concepts—entity, person, organism, object, place, event, action, information, property, group—and see which of them can be represented convincingly by existing Unicode symbols.
