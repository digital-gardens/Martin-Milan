## Priority Annotation System

User has a custom annotation system for organizing and prioritizing lines across markdown files:

- **More letters = higher priority**
- Format: `#aaaa`, `#aaaaa`, `#aaaaaa`, etc.

Priority scale (lowest to highest):
- `#a` — lowest priority above normal text
- `#aa` — 
- `#aaa` — 
- `#aaaa` — 
- `#aaaaa` — 
- `#aaaaaa` — 
- `#aaaaaaa` — highest priority so far

Used to tag/mark lines in knowledge base files for different levels of importance or attention. Integrated with Obsidian search (`tag:#aaaaaaa` queries).

**How to apply:** When helping organize, search, or filter content, recognize these markers as priority indicators. More a's = more important/urgent.
